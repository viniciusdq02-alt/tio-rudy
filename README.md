# Uncle Rudy — Landing Page (iOS 27 Concept)

Projeto front-end responsivo construído fielmente com base no layout de referência, aplicando boas práticas modernas de UI/UX, arquitetura CSS com Custom Properties, Grid/Flexbox fluido e animações com **GSAP + ScrollTrigger**.

## Estrutura de Pastas
- `index.html`: Marcação semântica com SVGs vetoriais nítidos.
- `css/styles.css`: Sistema de design dark-mode (`#050507`), Bento Grid responsivo e tipografia fluida.
- `js/main.js`: Orquestração de animações com GSAP + ScrollTrigger.
